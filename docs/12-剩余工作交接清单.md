## H-1 复测第 6 行：滚动加载后去重

**目标**：证明滚动出更多卡片后再读取，老笔记不会重复入库。

1. 打开小红书搜索结果页，搜 `广交会`，等卡片显示出来
2. **只用鼠标滚轮往下滚 3–4 屏**，再滚回顶部

5. 记下三个数字：`识别卡片 ___ / 成功提取 ___ / 跳过卡片 ___`
   - 自检：**成功提取 + 跳过卡片 必须等于 识别卡片**（这是缺陷 E 修复后新增的不变式）
6. **再点一次「读取当前页面笔记」**

| 现象 | 结论 |

# 7. 踩过的坑（每一条都真实发生过，别再来一次）

1. **Chrome 不会热更新**。`npm run build` 之后不点「⟳ 重新加载」，页面里跑的还是旧代码。曾经因此误判"修复无效"，浪费了一整轮复测。
2. **小红书的 `xsec_token` 不能重新编码**。它末尾带 `=`（base64 padding），`URLSearchParams` 会把它变成 `%3D`，导致打开笔记报 `error_code=300031 当前笔记暂时无法浏览`。所以 `buildNoteOpenUrl()` 是手工按 `&` 切分原始字符串再拼的，**不要重构它**。
3. **小红书笔记链接有三种路径形态**：`/explore/{id}`、`/discovery/item/{id}`、`/search_result/{id}?xsec_token=…`。`NOTE_PATH_RE` 必须全接受。另外**把 `/search_result/` 改成 `/explore/` 会让签名失效**。
4. **详情页是叠加层**。URL 变成 `/explore/{id}` 时，底下搜索结果的 DOM 并没有卸载。所以「DOM 里有 N 张卡片」不等于「当前是搜索结果页」。批量提取严格限制在 `search_results` 类型，这是**有意为之**。
5. **`Service Worker（无效）` 是正常状态**。MV3 的 Service Worker 空闲就休眠，不是报错。别去"修"它。
6. **`识别卡片` 必须等于 `提取 + 跳过`**。这是缺陷 E 修复后加的不变式，有测试锁着。如果你改了诊断字段，记得保持这条。
7. **登录墙检测是「任一选择器命中」语义**，不是"全部命中"。`docs/10` 里标的是"组级 measured"——能命中，但没逐条确认是哪一条。
8. **验证码/风控规则从未触发真实样本**，必须保持 `inferred`。**不要因为"看起来合理"就升级证据等级。**
9. **卡片字段选择器仍是 `inferred`**。真实页面只核对过**字段的值**，没采集过**命中的是哪条选择器**。要升级为 `measured`，需要人类在 DevTools 里逐条核对。
10. **`npm test` 偶发 `Hook timed out in 10000ms`**（`message-layer.test.ts`）。这是本机慢导致的偶发失败，单独重跑通常就过。**先重跑，不要急着改代码。**

# 8. 禁止事项（违反会破坏项目）

1. ❌ 自动发布评论、自动点赞/关注/私信
2. ❌ 绕过登录、验证码、风控；伪造请求签名
3. ❌ 调用未验证的平台内部接口、逆向私有 API
4. ❌ 上传账号凭证、Cookie、真实用户数据到任何服务器
5. ❌ 默认开启的第三方上传
6. ❌ `git add -A` / `git commit -a`
7. ❌ `git push origin main` / `--force`
8. ❌ 在别人有未提交改动时切分支或 `git reset`
9. ❌ 把 `inferred` 的选择器改成 `measured`（除非人类给了 DevTools 证据）
10. ❌ 把 H-1~H-3 标成"通过"而没有人类的真实数据
11. ❌ 推算「曝光量」「转化率」等未被记录的数据

任一条与需求冲突时，**停下来问人类**，不要自己决定（`AGENTS.md` §2 末尾）。
