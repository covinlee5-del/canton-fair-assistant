# 04 · 页面读取技术验证方案

> 原则：真实页面验证是唯一可信的"功能可用"证据；模拟页面测试只能证明提取逻辑正确，不能证明小红书页面可读。
> 未完成真实页面验证前，相关功能一律标记为"待验证"。

## 1. 验证方式：验证探针（Diagnostic Probe）

阶段 2 先交付一个**只读诊断探针**，不落库、不改页面：

- 用户点击扩展图标 → 打开侧边栏 → 点击"读取诊断"；
- SW 经 `chrome.scripting.executeScript`（activeTab）注入探针；
- 探针收集：页面类型信号、候选卡片计数、`/explore/` 链接计数、结构信号（标签名 + 关键属性，**不含任何文本内容**）、登录墙/验证码信号；
- 探针返回结构化 `ExtractionDiagnostics`，在侧边栏展示并可复制。

隐私约束：探针不读 Cookie、不读 localStorage、不截获网络；`pageUrl` 只保留 origin + pathname（去查询参数）；诊断不含笔记正文与用户信息。

## 2. 九项验证点（对应 PRD 5.1）

| # | 验证点 | 验证方式 | 成功条件 | 失败时的处理 |
|---|---|---|---|---|
| 1 | 用户能正常打开小红书搜索结果页 | 手动 | 浏览器展示笔记卡片 | 记录环境（未登录/风控/网络） |
| 2 | 插件能获得当前标签页权限 | 探针 | `executeScript` 注入成功并返回 | 提示"请在目标页面上重新点击扩展图标"；连续失败则评估站点权限（见文档 02 §6） |
| 3 | Content Script 能执行 | 探针 | 返回 `ExtractionDiagnostics` | 按错误码提示 |
| 4 | 页面实际可见 DOM 元素 | 探针 `signals` | 能统计候选卡片数与链接数 | 依据信号开发/修正适配器 |
| 5 | 稳定识别标题/链接/摘要/时间 | 提取统计 | `extracted + partial ≥ totalCandidates × 80%`；逐字段记录缺失率 | 调整选择器；若整体失败报 `DOM_STRUCTURE_CHANGED` |
| 6 | 加载更多后可再次读取新增 | 手动滚动 → 再次读取 | 新增笔记被识别；旧笔记全部被去重（`duplicates` 计数正确） | 检查 dedupeKey |
| 7 | 页面跳转后旧数据不误重读 | 换关键词搜索 → 再读取 | 同一笔记不重复创建 | 检查 canonicalUrl/指纹 |
| 8 | 登录状态变化的影响 | 未登录 vs 登录对比 | 未登录时得到 `LOGIN_REQUIRED` 而不是空数据或假数据 | 提示用户自行登录 |
| 9 | 结构变化导致的读取失败 | 长期：每次读取记录 `selectorVersion` + `signals` | 变化发生时能定位到信号差异 | 更新适配器选择器 |

## 3. 真实页面手动测试协议（阶段 2 探针交付后执行）

前置：Chrome ≥ 114；开发者模式加载扩展；用户已登录自己的小红书账号；测试记录填入 `docs/verification-results.md`（阶段 2 创建模板）。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 打开 xiaohongshu.com 首页并登录 | 正常登录 |
| 2 | 搜索"广交会"，等待结果加载 | 出现笔记卡片 |
| 3 | 点击扩展图标打开侧边栏 | 侧边栏打开且保持 |
| 4 | 点击"读取诊断" | 探针返回：pageType=search_results，noteSections>0 |
| 5 | 滚动加载更多后再次读取 | 候选数增加 |
| 6 | 切换关键词"interpreter"再读取 | 候选集合变化，新旧结果可区分 |
| 7 | 打开笔记详情页再点读取 | pageType=note_detail 或 UNSUPPORTED_PAGE 明确提示 |
| 8 | 在新标签页打开小红书并直接读取 | 观察 PERMISSION_DENIED 提示与引导是否出现 |
| 9 | 退出登录后再读取 | 出现 LOGIN_REQUIRED 提示，无假数据 |
| 10 | 触发验证码场景（如频繁操作）时读取 | 出现 CAPTCHA_OR_RISK_CONTROL 提示，不尝试绕过 |
| 11 | 记录测试日期、Chrome 版本、selectorVersion、signals 快照 | 形成真实验证记录 |

判定：步骤 1–7 全部符合预期 → 标记"小红书搜索结果页读取：真实环境验证通过（截至 YYYY-MM-DD）"。步骤 8–10 验证错误处理路径。

## 4. 模拟页面测试（阶段 3，证明提取逻辑正确）

fixtures 位于 `tests/fixtures/pages/`，经 jsdom 解析，验证适配器逻辑：

| fixture | 覆盖场景 |
|---|---|
| search-normal.html | 正常结果：10 条笔记，标题/链接/摘要/时间齐全 |
| search-empty.html | 无结果页 → NO_VISIBLE_NOTES |
| missing-title.html | 缺标题 → partial + missingFields |
| missing-link.html | 缺链接 → 走指纹兜底 |
| missing-time.html | 缺时间 → publishedAt=null |
| duplicate-notes.html | 重复笔记 → 去重计数 |
| changed-structure.html | 结构变化 → DOM_STRUCTURE_CHANGED |
| not-ready.html | 骨架屏 → PAGE_NOT_READY |
| login-wall.html | 登录墙 → LOGIN_REQUIRED |
| non-xhs.html | 其他站点 → UNSUPPORTED_PAGE |

**模拟测试通过只证明提取逻辑正确；真实页面验证（§3）通过后才允许对外声明可用。**

## 5. 错误码 → 用户文案映射

| 错误码 | 面向用户文案 | 调试信息（detail） |
|---|---|---|
| UNSUPPORTED_PAGE | 当前页面不是支持的小红书页面。请打开小红书搜索结果页后重试。 | pageUrl, pageType |
| PERMISSION_DENIED | 无法访问当前页面。请在目标页面上重新点击扩展图标，然后再试。 | tabId, 授权状态 |
| PAGE_NOT_READY | 页面内容还没加载完成。请稍候片刻再点读取。 | readyState, signals |
| NO_VISIBLE_NOTES | 当前页面没有识别到可读取的笔记。请确认你已打开小红书搜索结果页面，并等待内容加载完成后重试。 | signals 计数 |
| LOGIN_REQUIRED | 检测到需要登录才能查看内容。请先在小红书登录自己的账号，然后重试。 | signals.loginWallDetected |
| CAPTCHA_OR_RISK_CONTROL | 检测到验证提示。请在小红书页面手动完成验证后再读取；本插件不会绕过验证。 | signals.captchaDetected |
| DOM_STRUCTURE_CHANGED | 页面结构似乎发生了变化，暂时无法完整识别笔记。建议更新插件版本；当前数据已尽力保留。 | selectorVersion, signals |
| EXTRACTION_PARTIAL | 部分笔记的信息不完整（如缺少时间），已提取可见内容。 | missingFields 统计 |
| STORAGE_ERROR | 保存数据失败。请检查浏览器磁盘空间后重试；本次读取结果尚未保存。 | cause |
| IMPORT_INVALID | 导入文件格式不正确或不兼容。已拒绝导入，原有数据未受影响。 | 校验错误明细 |
| INVALID_INPUT | 输入内容不合法，请检查后重试。 | 校验失败的字段与规则 |
| UNKNOWN_ERROR | 发生未知错误。请重试；若持续出现，请导出诊断信息反馈。 | cause |

## 6. 长期回归机制

- 每次读取记录 `selectorVersion`、`signals` 与时间；若后续读取出现 `DOM_STRUCTURE_CHANGED` 或提取率骤降，通过诊断对比定位变化。
- 真实页面测试协议（§3）在平台明显改版后重新执行一遍，并更新"真实环境验证通过"的日期标记。
